# Gerador de Informativos — Grupo Fresh Food

Materiais de design para comunicação interna do Grupo Fresh Food: fundos e
templates prontos para montar comunicados, cartazes, e-mails, apresentações e
infográficos, além do logo oficial.

## O que tem aqui

- **Templates para comunicados/Digital/** — fundos para peças digitais:
  cartaz (1080×1080 e 1080×1350), banner de e-mail (1200×400), infográfico,
  mural de TV (1920×1080) e capa/conteúdo de PPT (16×9).
- **Templates para comunicados/Impresso/** — fundos para impressão A4:
  cartaz, infográfico e cabeçalho de Word.
- **logo-fresh-food.png** — logo oficial.

## Como usar

Baixe o fundo do formato desejado e monte o conteúdo por cima (Canva, PowerPoint,
Word ou editor de imagem). Os tamanhos já estão no nome de cada arquivo.
